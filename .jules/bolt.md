## 2024-05-18 - [Parallelize Independent Async Work in PDF processing]
**Learning:** In operations that process multiple independent items asynchronously (e.g. converting multiple images to PDF, merging multiple PDFs), doing `await` inside a `for` loop executes them sequentially, creating a bottleneck. However, the `pdf-lib` method `addPage()` can be tricky when pages are modified out of order. Some tasks, like loading buffers or embedding images, are entirely independent and can be parallelized with `Promise.all()`, leaving only the state-modifying operations (like `addPage()`) sequential to preserve ordering.
**Action:** Identify `for` loops in tools like `MergePDFTool` or `ImageToPDFTool` that await independent IO or parsing tasks. Parallelize the independent work (e.g., `arrayBuffer()`, `PDFDocument.load()`, `embedJpg()`) using `Promise.all()`, then process the results sequentially to preserve order.
