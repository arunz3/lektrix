## 2024-05-18 - Missing ARIA Labels on Icon Buttons\n**Learning:** Found multiple instances where Lucide React icons were used inside buttons without accompanying `aria-label` attributes, impacting screen reader accessibility.\n**Action:** Always verify that buttons containing only icons (e.g., 'X' close buttons, 'Star' ratings, 'Rotate' icons) include a descriptive `aria-label` attribute for accessibility.
