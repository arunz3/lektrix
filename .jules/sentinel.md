## 2025-02-26 - Prevent Object URL Memory Leaks / DoS Vulnerability
**Vulnerability:** Unbounded creation of Object URLs via `URL.createObjectURL(file)` when processing massive user uploads. The `handleFiles` function in `src/App.jsx` generated memory-heavy Blob URLs for every uploaded file *before* limiting the array size based on application constraints (`maxFiles`). This could lead to client-side out-of-memory (OOM) errors and application crashes (Denial of Service).
**Learning:** Even though the application logic later discards the extra files by slicing the array, the browser memory was already consumed by generating the object URLs for the discarded files, and these unused previews were never tracked or explicitly revoked because they were immediately dropped from the state.
**Prevention:** Always enforce constraints (like `slice(0, maxFiles)`) *before* executing expensive or memory-allocating operations (`URL.createObjectURL`, rendering canvas, etc.) on arrays of unbounded user input.
