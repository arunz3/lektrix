## 2024-05-18 - Hardcoded API Key in Demo Mode Fallback\n**Vulnerability:** A hardcoded Web3Forms API key was embedded directly in `src/App.jsx` to power a "demo mode" for a feedback form. \n**Learning:** Developer convenience features (like demo modes) often introduce hardcoded secrets if not carefully designed around environment variables. The fallback logic was checking for the presence of the specific hardcoded "dummy" string instead of checking for the absence of an environment variable.\n**Prevention:** Never use hardcoded strings for secrets, even for demo environments. Structure application logic to check if an environment variable is falsy (`if (!ENV_VAR)`) to enable demo modes or fallback behavior, rather than matching against a hardcoded string.
